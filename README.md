# SEVIMLI — маркетплейс для женщин 💗

Маркетплейс товаров и услуг для женщин Узбекистана: одежда, косметика, детские товары,
дом, аптека и салоны красоты с онлайн-записью.

**Стек:** Next.js 16 (App Router) · TypeScript · Tailwind CSS v4 · Supabase · Zustand.

## Быстрый старт

```bash
npm install
npm run dev
# http://localhost:3000
```

По умолчанию в `.env.local` стоят **заглушки** — сайт сразу работает на демо-данных
(`lib/demo.ts`): главная, каталог, карточки товара и магазина, корзина.
Чтобы включить реальную базу, авторизацию, заказы и загрузку фото — см. **[DEPLOY.md](DEPLOY.md)**.

## Возможности

- 🏠 Главная: Hero-поиск, 8 категорий, популярные магазины, новинки
- 🛍️ Каталог с фильтрами (цена, город, сортировка) и пагинацией
- 📦 Карточка товара: галерея, отзывы, похожие, «В корзину» / «Купить сейчас»
- 🛒 Корзина (Zustand + localStorage) и оформление заказа
- 🔐 Авторизация (Supabase Auth), профиль с заказами и записями
- 🏬 Кабинет продавца: дашборд, товары (загрузка фото), заказы, записи, настройки магазина
- 💆 Онлайн-запись в салоны (BookingModal)
- 🔎 Поиск по товарам и магазинам

## Структура

```
app/              — роуты (App Router)
components/        — UI-компоненты (карточки, секции, формы, кабинет продавца)
lib/              — Supabase-клиенты, слой данных, типы, демо-данные, утилиты
store/            — Zustand-стор корзины
supabase/         — SQL-миграция (001_init.sql)
```
