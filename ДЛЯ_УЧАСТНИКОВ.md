# SEVIMLI — MVP для участников команды

**SEVIMLI** — цифровая экосистема для женщин Узбекистана: сообщество, магазин и услуги
в одном приложении. Женщина обсуждает, покупает проверенное и записывается к мастеру —
не выходя из одного доверенного пространства.

Подаёмся на **President Tech Award, трек Incubation** (грант $40 000).

## В чём идея (коротко)

**Проблема.** У женщины в Узбекистане нет одного места «для себя». Совет она получает
в Telegram-группе, покупает — на обезличенном маркетплейсе, мастера ищет по сарафану.
Там, где доверие — нет кассы. Там, где касса — нет доверия.

**Решение.** Сообщество в ядре + магазин + услуги в одном контуре. Доверие сообщества
конвертируется в покупку на месте.

**Модель проверена:** Xiaohongshu (Китай) — 300 млн+ MAU, ~70% женщин, выручка $4,8 млрд
за 2024 на связке «сообщество → покупка».

**Точка входа — K-beauty.** Корея даёт 35% импорта косметики в Узбекистан, но официального
канала оригинальной корейской косметики в стране нет. Острая боль + частые покупки =
дешёвый способ завести аудиторию. Дальше — одежда, салоны, детские товары, дом.

## Что уже сделано

- Работающий MVP (Next.js 16 + React 19 + Tailwind v4 + Supabase-ready)
- Сообщество: лента, посты 3 типов, лайки, комментарии, теги, Q&A на карточках товаров
- Магазин: каталог с фильтрами, карточка товара, корзина, оформление заказа, поиск
- K-beauty-лендинг с гарантией подлинности и сравнением цен
- Карта лояльности: 4 уровня, кешбэк, начисление баллов с заказов
- Кабинет продавца: дашборд с метриками, товары, заказы, записи, настройки магазина
- Салоны: страница магазина + онлайн-запись (услуга/дата/слот)
- Питч-дек под President Tech Award (10 слайдов)

## Что предстоит

## Для разработчиков — запуск локально

Нужен Node.js 20+.

```bash
npm install
npm run dev
```
Открыть http://localhost:3000

Боевая база — по инструкции в `DEPLOY.md` (миграции в `supabase/migrations/`).

**Стек:** Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS v4,
Supabase (@supabase/ssr), Zustand (persist).

## Нужны в команду

Трек Incubation требует **2–5 человек**. Ищем:

- **Операции / закупки** — работа с корейскими поставщиками, логистика, растаможка
- **Комьюнити-менеджер** — поднять женское сообщество, посевы в Telegram/Instagram
- **Продажи / B2B** — подключение салонов и продавцов

Если тема откликается — пиши основателю.
